# A3 App 认证联调专用步骤清单（子集，非正式初始化）
#
# 用途：给 A3 联调建隔离测试库。正式初始化请用 scripts/db/init-steps.txt。
#
# 注意：smartscript_full_init.sql 已自幂等（含完整基线 + 全部增量），
#       本子集直接复用它；联调库中会包含产品菜单数据，对 App 认证联调无影响。
#
# 用法（示例，库名与账号按本机实际替换）：
#   export DB_PASSWORD='<口令>'
#   ./scripts/db/init-database.sh -d ruoyi_dev_a3_test -u root \
#       --steps scripts/a3/init-steps-a3.txt
#
# 反复联调需要重建测试库时，请先自行确认并删除该测试库：
#   mysql -e "DROP DATABASE IF EXISTS \`ruoyi_dev_a3_test\`;"
# 破坏性动作不藏在脚本里，是为了避免误删非测试库。
#
# 格式与 scripts/db/init-steps.txt 一致：<步骤ID>|<闸门>|<仓库根相对路径>|<说明>
