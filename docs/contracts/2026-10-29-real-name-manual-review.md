# 实名认证：阿里云核验与人工审核

本契约取代 2026-10-19 自动决定审核结果的部分。首次提交和驳回重提均使用原路径，content-type 为 multipart/form-data：realName、idNumber、front、back。正反面均为必填图片，原始文件每张不超过 5 MiB；服务端验证实际格式和尺寸并转为 PNG，存放在私有材料目录中。旧 JSON 请求不再满足提交条件。APP 与创作者网页使用同一接口。

输入校验通过后调用阿里云二要素核验；不匹配返回可纠正错误，通道不可用时不产生申请。核验成功创建 PENDING 申请，运维使用独立权限 user:realname:audit 通过或驳回，驳回需填写原因。决定使用预期状态并发保护，提交通知沿用既有机制。通过后写入合同所需姓名快照；待审核姓名在任何审核决定后清除。证件号只保存掩码。

详情按 user:realname:query 权限提供短期一次性材料访问令牌，顺序为正面、反面；历史单材料记录继续可读。列表不返回材料。上线前须运行 sql/migrations/a/A_20261029_001__real_name_manual_review.sql，并向需要的运维角色授予审核权限。配置私有材料目录及现有阿里云核验服务。
