- 最终 JAR 的本地真实 HTTP：8 个检查通过，涵盖短信登录、getInfo、首次设密码、密码登录、PC 统一登录、双域互相拒绝、单设备退出、停用/启用不复活旧令牌、改密及已删除刷新入口返回 404。临时账号与角色已清理；未输出密码或令牌。

## 本地运行与兼容性

后端在独立 Git 工作树完成测试、打包与真实 HTTP 验证，避免正在使用的目标 JAR 文件锁定。App debug APK 构建通过，保持 `http://10.0.2.2:8080/api/v1` 地址。

旧 App JWT 不能换成新若依会话，升级后需要重新登录；历史刷新令牌从 App 安全存储中移除。旧 JWT 签发器、刷新轮换服务、DTO、数据库映射、刷新接口、独立密钥配置及其历史测试已删除。历史数据库表保留但不再访问。

本次登录迁移不修改数据库结构。原有资料名称、系统管理、SQL 和本地配置改动保持，不属于本次提交范围。验证使用实际待提交的隔离分支，不包含这些工作区改动。
